Changes is installed

Standalone: open Changes from Applications or Launchpad. The first time, choose your audio output and MIDI keyboard in Options → Audio/MIDI Settings.

Logic Pro / GarageBand: create a Software Instrument track and choose AU Instruments → JazzyT Audio → Changes.

Other DAWs: rescan plug-ins and load Changes (VST3) on an instrument track.

The manual is in /Library/Application Support/JazzyT Audio/Changes/.
